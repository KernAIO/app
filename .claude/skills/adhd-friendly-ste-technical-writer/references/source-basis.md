# Source Basis

This reference records the sources used to shape `adhd-friendly-ste-technical-writer`. The pasted request is the primary synthesis. External sources support the distinction between official ASD-STE100 rules and the recommended ADHD-oriented additions.

## Official ASD-STE100 sources

- Issue 9 PDF: https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf
- ASD-STE100 overview: https://www.asd-ste100.org/about_STE.html

Use these sources when a document makes an exact official-STE claim. The skill must not present its stricter sentence targets, progress indicators, resumability rules, or cognitive-accessibility framing as official ASD-STE100 requirements.

The request attributes these baseline rules to ASD-STE100:

- Procedural sentences: maximum 20 words.
- Descriptive sentences: maximum 25 words.
- Instructions: one instruction per sentence, with imperative wording for procedures.
- Descriptive paragraphs: one topic, a topic sentence first, and no more than six sentences.
- Conditions: put a condition before the dependent instruction.
- Vocabulary: use controlled and consistent terms.

## W3C cognitive-accessibility source

- Making Content Usable for People with Cognitive and Learning Disabilities: https://www.w3.org/TR/coga-usable/
- Design Guide: https://www.w3.org/TR/coga-usable/design_guide.html

The request uses the W3C guidance to support short paragraphs, topic-based lists, explicit steps, clear headings, reorientation after distraction, reduced memory demands, streamlined required workflows, progress information, and sufficient information to verify each step.

## House rules introduced by this skill

These are recommendations, not official ASD-STE100 requirements:

- Target 8–15 words per sentence.
- Prefer a soft limit of 18 words.
- Put one action on one line or numbered step.
- Use 2–4 sentence paragraphs normally.
- Use literal, search-like headings.
- Repeat important nouns and local context.
- Separate required information from optional information.
- Show progress in long procedures.
- State an observable expected result after important actions.
